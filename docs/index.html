AI 错题复习平台

拍照即可收录错题，AI 自动识别题干、答案与错因，按知识点归类，生成相似题练习，并按记忆曲线安排复习。手机、平板、电脑都能用。

核心能力

📷

拍照识题

上传或拍摄题目照片，视觉大模型自动提取题干、答案、解析与错因。

🧩

知识点归类

按学科、年级、学期与知识点打标签，构建个人错题知识网络。

🔁

举一反三

基于原题自动生成同知识点变式题，检验是否真正掌握。

📅

间隔复习

依据记忆曲线安排复习计划，到期自动提醒，减少遗忘。

📊

学习统计

错题数量、学科分布、掌握率可视化，薄弱环节一目了然。

🖨️

导出打印

按筛选条件导出错题集，支持 PDF 打印，方便线下练习。

部署只需三步

STEP 01

创建 Supabase 项目

在 Supabase 新建项目，复制连接串（连接池 6543 与直连 5432）。

STEP 02

导入仓库到 Vercel

点击上方「一键部署」，或手动导入 GitHub 仓库。

STEP 03

填写环境变量

配置 DATABASE_URL、DIRECT_URL、OPENAI_API_KEY 等，部署即可。
